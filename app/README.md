# Controlled mobile app

Expo React Native client for Controlled, targeting Android and iOS. The current UI implements the supplied onboarding reference through the initial greeting screen. Authentication actions are intentionally local navigation placeholders until the API integration pass.

## Run locally

Use Node 24, then install dependencies and start Expo from this directory:

```bash
nvm use
npm install
npm start
```

From the Expo terminal, press `a` for Android or `i` for iOS. You can also run a platform directly:

```bash
npm run android
npm run ios
```

## Checks

```bash
npm run lint
npm run typecheck
npx expo-doctor
```

The native application identifiers are `com.fromh.controlled` on both platforms. Native `android/` and `ios/` projects are generated by Expo when needed and are intentionally not committed.
